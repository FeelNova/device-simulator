# 最小 MQTT OTA 模拟测试

1. 打开 `/ota`, 填写连接信息, 独立 `sim-` token, 型号 `sim-esp32`, 当前版本.
2. 需要新测试版本时, 设置 mock target version 并下载 mock 文件, 在管理端填写需要测试的型号/版本后上传发布. mock 文件可重复用于不同测试版本, 文件内型号/版本不参与校验. 不可使用普通文件或真实固件充当 mock.
3. Connect & register 后保持页面打开, 应用首页使用同一 token 连接.
4. 应用比较注册版本与该连接选定的已发布版本; 需要升级时下发命令 13.
5. 模拟器实际下载并校验 mock, 模拟安装和重启后, 通过新注册上报目标版本. 不发送升级进度, 成功/失败状态或版本查询回复.
6. server 只通过新注册判断结果: 目标版本确认成功, 旧版本或缺失/无效版本结束为未验证. 普通心跳不完成升级. 没有注册时结果保持未知, 五分钟仅为预估.

Scenario 已移除. 下载异常只显示在模拟器本地日志, 不上传失败状态. 可手动断开, 将当前版本保持为旧版后重新注册, 验证未完成升级路径.

MQTT OTA 支持型号由服务端 FIRMWARE_OTA_DEVICE_TYPES 配置, 默认只包含 sim-esp32. 有版本字段不代表真实硬件一定支持命令 13. 请勿复用真实设备 token.

下载桥接保留 OTA_SIMULATOR_ORIGIN 和 OTA_DOWNLOAD_ORIGINS 环境配置, 仅允许指定来源的签名下载路径. MQTT 密码不存入 localStorage.

Broker 输入框提供 Preprod 和 Test site 两个快捷按钮, 点击只更新地址, 不自动连接. 仍可手动输入自定义地址. 连接或升级期间禁用切换, 需先断开再换环境. 两个环境的设备注册及固件库独立, 切换后需重新注册.
